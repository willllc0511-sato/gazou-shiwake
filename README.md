# 商品写真の仕分け（見本）

写真を1枚上げると、何が写っているかを画像認識で判定し、ネットショップの仕分け先（衣類・靴・電子機器・台所用品・食品・家具など）を返すウェブアプリです。
応募用に作った見本です。お客さまの案件ではありません。

- 作った人：合同会社Will（髙城）

## できること

- 写真を選ぶと、上位3件の分類と確からしさ、仕分け先を表示します
- 判定の履歴をデータベース（PostgreSQL）に残し、画面に最近20件を出します
- 写真そのものとファイル名は保存しません。照合用のハッシュ値と結果だけ残します

## 使っている技術

| 役割 | 使ったもの |
|---|---|
| API・画面 | Python 3.12 / FastAPI / 素の HTML と JavaScript |
| 画像認識 | ONNX Runtime（CPU）で MobileNetV2（ImageNet 1000分類）を動かす |
| データベース | PostgreSQL 16 / SQLAlchemy 2（テストは SQLite） |
| 実行環境 | Docker / Docker Compose、手前に nginx（HTTPS） |
| テスト | pytest（正常な場合・壊れた入力・攻撃を想定した入力） |

外部の AI サービスは呼ばず、サーバーの CPU だけで判定します。1枚あたりの利用料はかからず、判定は1枚20〜30ミリ秒です（3コア・メモリ2GBの小さなサーバーで実測）。

## 構成

```
ブラウザ ──HTTPS──> nginx ──> app（FastAPI・画像認識） ──> db（PostgreSQL）
                    │                     └ 学習済みモデル（作るときに照合値を確かめて取り込む）
                    └ 10MB を超える送信はここで止める
```


## 設計で気をつけたこと

- **壊れた写真・細工した写真で止まらない**：画像として読めない物、10MB を超える物、展開すると巨大になる画像（4,000万画素を超える物）は、日本語で理由を返して断ります
- **連打で占有されない**：送り元ごとに1分20回までにしています。送り元の判定は、手前の nginx から来た時だけ X-Real-IP を信じ、外から付けられた偽のヘッダーは使いません
- **中の情報を外に出さない**：予期しないエラーでも決まった文だけを返し、スタックトレースや内部のパスは出しません。API の説明ページ（/docs）も閉じています
- **秘密を置かない**：データベースのパスワードは Docker の secrets で渡し、環境変数やリポジトリには書きません
- **モデルのすり替えを防ぐ**：学習済みモデルは、作るときに SHA-256 の照合値が一致した物だけを取り込みます
- **仕分けの当て方**：分類名を単語の区切りで当てます（"cap"（帽子）が "capuchin"（猿）に当たらないように）。上位3件の合計が20%に届かなければ「要確認」にします
